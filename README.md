# Anika Tabassum — Portfolio

My personal portfolio website, built with plain **HTML, CSS and JavaScript** (no frameworks).

🔗 **Live:** https://anikat19.github.io

## Features
- Responsive design (desktop + mobile menu)
- Dark / light theme toggle that remembers your choice
- Typing animation in the hero section
- Project cards generated from a JavaScript data array, with category filters
- Certifications section with Credly verification link
- Fade-in animations on scroll

## Project structure
```
├── index.html     # page layout and sections
├── style.css      # styling and theme colors
├── script.js      # project/skill data + interactivity
└── assets/
    ├── Anika_Tabassum_CV.pdf
    ├── cisco-ccna-itn-badge.png
    └── Cisco_CCNA_ITN_Certificate.pdf
```

## Updating content
All projects and skills live at the top of `script.js` — add a new project by copying one block in the `projects` array.
